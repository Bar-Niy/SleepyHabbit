# SleepyHabbit

A Flutter app that helps you improve your sleeping habits through AI-powered voice diary conversations, meal tracking, and personalized sleep analysis.

## Features

### Customizable Alarm Clock
- Set multiple alarms with flexible scheduling (per-day-of-week)
- Configurable snooze duration and max snoozes
- Full-screen alarm with vibration support

### Morning Interview (Post-Alarm)
- After dismissing the alarm, the app asks about your sleep via TTS
- Questions are dynamically generated by an LLM (adapts to your responses)
- Your voice answers are recorded, transcribed, and stored locally
- The LLM summarizes the interview for insights

### Evening Diary
- Before sleep, the app acts as a "thought offloading" companion
- Guides you through your day (highlights, worries, gratitude)
- Based on research showing that journaling before bed reduces racing thoughts
- All conversations stored locally and summarized by AI

### Meal Tracking
- Snap photos of meals throughout the day
- AI analyzes how meal timing/content might affect sleep
- Periodic reminders to log meals

### Sleep Insights
- AI-powered pattern analysis correlating meals, diary entries, and sleep quality
- Weekly summaries with trends
- Personalized actionable tips

### Privacy-First Design
- All data stored locally on-device (SQLite/Drift)
- LLM can run entirely on-device (llama.cpp) or connect to external API
- Google Drive backup goes to YOUR account only
- No data collection, no ads, no tracking

## Getting Started

### Prerequisites
- Flutter SDK >= 3.2.0
- Android Studio / Xcode

### Setup

```bash
flutter pub get
dart run build_runner build  # Generate Drift database code
flutter run
```

### LLM Configuration

By default, the app connects to a local llama.cpp server at `localhost:8080`. You can configure any OpenAI-compatible API (Ollama, Groq, etc.) in Settings > AI Configuration.

For fully on-device AI:
1. Install [llama.cpp](https://github.com/ggerganov/llama.cpp) server
2. Download a small model (e.g., Llama 3.2 3B)
3. Run the server: `./server -m model.gguf --port 8080`

## Privacy & Legal

- **No server-side data collection** - everything is local
- **Voice data stays on device** - recordings transcribed locally
- **Backup to YOUR cloud** - only Google Drive (your account)
- **LLM choice** - use local models for zero network exposure
- Full Terms of Service and Privacy Policy included in-app
